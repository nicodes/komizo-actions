# Application independence

These actions are reusable across applications and accounts. Do not select
behavior by a fleet app name, business-specific credential, provider or domain.
Callers declare app metadata and capabilities; the host operator authorizes
privileged adapters and profiles. Keep injection checks, metadata-only scoped
transport, exact profile/generation comparison and per-app host permissions.
Private fleet inventory, operating instructions and measurements belong in
`nicodes/docs`. Public usage README content is generated from that repository.
